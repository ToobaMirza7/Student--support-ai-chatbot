# CampusAssist AI

AI-based student support chatbot designed to provide quick assistance for common student queries.

## Features

- Course-related queries
- Attendance information
- Examination guidance
- Fee-related queries
- Library information
- Interactive chatbot interface

## Technologies Used

- Python
- Basic Natural Language Processing concepts

## How It Works

The chatbot accepts a student's query, identifies relevant keywords, and provides an appropriate response from its predefined response categories.

## How to Run

1. Install Python 3.
2. Download this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
python chatbot.py
